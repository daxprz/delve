# `delve/goals/`

Operator-facing GOALs (the prose-level "what are we actually trying to do right now" anchor). One file per GOAL (`GOAL-<scope>-NNN-<slug>.md`); `goals/active.md` is the auto-regenerated rollup that every session loads.

Mint via `ccc-bd new goal <effort> <slug> --title "..."`. Inspect via `/goals` slash command. See `/var/ccc/workspace/docs/work-platform.md` § GOAL.
