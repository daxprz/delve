# The Runner's physics tail

## Summary

Give the **Runner** a long procedural **physics tail** that sways as it
moves and wags slowly on its own — the Runner's signature look (the
Grabber's is the arms).

## Definition of Done

- [x] The Runner has a long physics tail; the Grabber does not.
- [x] The tail is a stable physics chain that hangs and drags.
- [x] The tail wags slowly by itself.
