# `delve/effort/`

Work-platform artifact tree — DESIGNs, EPICs, STORYs, TASKs, HUGs, MILESTONEs. One directory per effort (e.g. `effort/onb/`, `effort/flow/`). See `/var/ccc/workspace/docs/work-platform.md` for the full vocabulary and XID format.

Mint via `ccc-bd new <kind> <effort> <slug> --title "..."`. The wrapper creates the per-effort sub-tree on first use; you don't need to pre-create `effort/<effort>/`.
