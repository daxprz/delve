# A single giant spider that lumbers

## Summary

One spider, not two — and it should feel **giant**: slow, heavy,
thick-legged, taking big deliberate strides, and hard to knock over.

Its legs also gain a **third** segment right next to the body, so a
leg goes **down, then up, then down** — the real spider shape, where
the leg drops off the body before rising to the knee.

Six changes together:

| | |
|---|---|
| **one** | only a single spider in the world |
| **slower** | it lumbers instead of scuttling |
| **big steps** | fewer, longer strides — not quick little ones |
| **thicker** | legs heavy enough to carry something that size |
| **sturdier** | much harder to knock down |
| **3 joints** | down, up, down — a segment next to the body |

## Definition of Done

- [ ] Exactly one spider in the world.
- [ ] It moves clearly slower than the Walker.
- [ ] Its legs are visibly thicker.
- [ ] Each leg has 3 segments; the first goes DOWN from the body, the
      second UP, the third DOWN to the floor — measured.
- [ ] Its feet still reach the ground.
- [ ] It takes fewer, longer strides.
- [ ] It takes a much harder hit to knock over than a Walker.
- [ ] Still ragdolls when hit hard enough — sturdy, not invincible.
- [ ] Diagonal-pair walking still holds.

## Out of scope

- Eight legs.
